# UzbechiGPT — AI Chat & Image Generation

UzbechiGPT is a modern, responsive conversational AI assistant with age-adaptive user experience, native trilingual support (O'zbek, Русский, English), and high-resolution **Pollinations Flux** AI image generation.

## 🌟 Key Features

- ✦ **Age-Adaptive Themes**:
  - **Kids (7–10)**: Playful, warm, cheerful UI.
  - **Teens (11–14)**: Cyberpunk neon gradients.
  - **Adults (15+)**: Sleek, minimalist dark monochrome.
- 🎨 **Image Generation (Pollinations Flux)**:
  - 100% free image generation powered directly by Pollinations Flux.
  - No Google AI billing or credit card required.
  - Full-size preview, lightbox zoom, and direct `.png` download.
- 💬 **Conversational Chat**:
  - Real-time token streaming powered by Gemini 3.5 Flash.
  - File attachments (documents, images, code).
- 🎬 **Video Generation**:
  - Powered by Google Veo.
- 🌐 **Native Trilingual Support**:
  - O'zbekcha, Русский, English.

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Configure Environment
Create a `.env` file in the project root:
```env
GEMINI_API_KEY="your_gemini_api_key_here"
PORT=3000
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Production Build
```bash
npm run build
npm start
```
